# TodoJumPhp

a example of cli jumphp

**Try it: https://jumphp.net/todojumphp**

Made with [JumPHP](https://github.com/davidnurdin/jumPhp): games and applications in PHP, on the desktop and in the browser.
The application is in `games/todojumphp/`.

```bash
bin/jumphp install todojumphp    # dependencies (everything runs in Docker)
bin/jumphp run todojumphp        # run it on the desktop
bin/jumphp test todojumphp       # checks + a headless demo
```
