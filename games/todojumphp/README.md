# todojumphp

A JumPHP CLI app: commands and a full-screen screen in the terminal (Symfony Console + symfony/tui).

```bash
bin/jumphp install todojumphp
bin/jumphp run todojumphp                 # the full-screen screen (arrows, Enter, a, d, q)
bin/jumphp run todojumphp add "Buy milk"  # a command; list-tasks, done 1, --help
bin/jumphp test todojumphp
bin/jumphp export:standalone todojumphp --linux --windows --macos
```
